首次提交：内核 overlay 定制框架搭建（学习项目）

一、框架结构
- 内核树（../linux-imx6ull-kernel-code）保持 master-gengtao-0901 纯净基线，
  所有定制放本 overlay，构建时拷贝覆盖
- common/：公共定制层（当前为 scripts/dtc 的 extern yylloc 构建补丁，
  适配宿主机 GCC 13 的 -fno-common）
- projects/gengtao-bsp-0901/：板级定制层（从零开始，逐外设添加 dts/驱动/defconfig）
- .baseline/：修改文件的基线侧快照（未来内核升级冲突检测）
- MANIFEST：定制清单（基线 sha + 文件列表），驱动 apply 校验与 dtb 目标提取
- gengtao-bsp-doc/：学习笔记与问题复盘文档（01-内核BSP框架搭建与启动问题复盘）

二、脚本工具链（scripts/，详见 scripts/README.md）
- common.sh            公共库：路径/工具链常量、layer_for 分层规则、safe_reset 安全重置
- apply_overlay.sh     overlay → 内核树（先 common 后 project），校验 MANIFEST 完整性
                       与 dts/Makefile 接线
- build_kernel.sh      一键构建：重置基线 → apply → distclean/defconfig → zImage
                       + dtb（从 MANIFEST 动态提取）+ modules → 打包到 ../output/<project>/
- update_board.sh      部署产物到 TFTP/NFS，板子复位验证（tftp/nfs/all 模式）
- capture_changes.sh   内核树手工修改回收到 overlay（编辑-编译-回收闭环）
- extract_overlay.sh   从 git 分支差异提取定制重建 overlay（慎用：--branch IMX6
                       会提取出厂全部定制）
- restore_baseline.sh  内核树恢复干净基线

三、关键设计
- BASE_BRANCH=master-gengtao-0901；safe_reset 在非基线分支上一律 checkout
  而非 reset --hard，保护分支历史
- 设备树目标列表由 MANIFEST 动态提取：新增 dts 即自动编对应 dtb
- apply 时校验新增 dts 是否在 dts/Makefile 接线（防漏接，报错提示明确）
- 产物树外输出到 ../output/gengtao-bsp-0901/，内核树随时可恢复纯净
