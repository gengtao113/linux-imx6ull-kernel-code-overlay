# 变更说明（仓库：linux-kernel-overlay）

## 一句话

7 寸屏从「只能显示」升级为「可显示 + 可触摸」：屏上的电容触摸已打通，Linux 能拿到触点坐标，LVGL 能据此响应点击。

## 提交说明

ALPHA 底板 7 寸 RGBLCD 模组上，除显示外还带一块**电容触摸 IC（Goodix gt9xx）**，走 I2C2、地址 `0x5d`（板上实测确认）。本次把它从「原理图上有」变成「软件能用」：

1. **腾出被占用的引脚** —— 关掉 SoC 自带的电阻触摸（`&tsc`）；SD 卡供电、LCD 复位之前占着触摸要用的中断 / 复位两根脚，一并让出来。
2. **设备树挂上触摸** —— 在 I2C2 下声明 `goodix_ts@5d`，指明中断（CT_INT）、复位（CT_RST）引脚。
3. **引入现成驱动** —— 内核自带 gt9xx 触摸驱动，`CONFIG_TOUCHSCREEN_GT9XX=y` 编入，不用自己写。
4. **对上输入子系统** —— 驱动把坐标经 input 子系统上报到 `/dev/input/event1`，LVGL 用 evdev 读取。

## 交付结果（业务）

| 能力 | 状态 |
|------|------|
| 显示 | 不变（1024×600 LCD） |
| 触摸输入 | 新增：`goodix-ts` → `/dev/input/event1`，摸屏有 EV_ABS 坐标 |
| 上层点控 | LVGL `EVDEV_NAME=/dev/input/event1`（待板上最终确认） |

## 技术实现（开发者看）

### 设备树

`projects/gengtao-bsp-0901/arch/arm/boot/dts/imx6ull-14x14-evk-emmc-gengtao0901-1024-600.dts`：

| 改动 | 业务含义 |
|------|---------|
| `&tsc` → `disabled` | 不用 SoC 电阻触摸，改用屏上电容触摸 |
| `&reg_sd1_vmmc` 删 `gpio` | 让出 GPIO1_IO09 给触摸中断（否则 gt9xx `-EBUSY`） |
| `pinctrl_hog_1` 去掉 GPIO1_IO09 | 同上，释放 CT_INT |
| 新增 `ts_int_pin` / `ts_reset_pin` | 声明触摸的中断 / 复位引脚 |
| `&i2c2` 挂 `goodix_ts@5d` | 触摸 IC 挂 I2C2，地址 `0x5d` |
| `&lcdif` 不挂 reset | LCD 复位与触摸复位同脚，避免 probe 冲突 |

## 业务验收（板上）

- `i2cdetect -y 1` 扫到 `0x5d` → 芯片在位、I2C 通路正常
- `dmesg` 出现 `goodix-ts` → 驱动已接管
- `hexdump -C /dev/input/event1` 摸屏有坐标 → 触摸数据已上报
- LVGL `EVDEV_NAME=/dev/input/event1` → 上层可点（L5 待最终确认）
