# 08 1024×600 屏幕打通-问题复盘

> 文档编号：08  
> 日期：2026-09-01  
> 板卡：正点原子 ATK-MX6ULL（CORE V2.0 + ALPHA V2.4）  
> 屏幕：ATK-7RGBLCD 7 寸 **1024×600** RGB 并行  
> 关联：`03`（U-Boot/dtb）、`04`（原理图）、`07`（分析与落地顺序）  
> 结果：✅ `/dev/fb0` = 1024×600；背光可调；屏显已打通

## 一、目标与显示链

```text
应用 / dd / 控制台
      ↑
/dev/fb0（mxsfb）
      ↑
LCDIF + display-timings（1024×600 @ ~51.2MHz）
      ↑
pinctrl：DATA0~23 + PCLK/HSYNC/VSYNC/DE + 复位
      ↑
PWM1 背光（GPIO1_IO08 / BLT_PWM）
```

目标：在 NXP 纯净基线 + overlay 框架下，把定制 dtb 从「文件名写着 1024-600、内容仍是小屏时序」改成真正 1024×600，并完成板上可见显示。

## 二、现象时间线

| 阶段 | 关键现象 | 结论 |
|------|----------|------|
| A. 起点 | 定制 dtb 名含 `1024-600`，基线 `&lcdif` 仍是 **480×272 / 9.2MHz** | **文件名 ≠ 内容**；未覆盖时序 |
| B. 原理图梳理 | CORE/ALPHA/屏模组：24bit RGB + PWM 背光 + 复位；800×480/1024×600 同座 | 无需新驱动，改 dts 时序即可 |
| C. 第一次改 dts | 在板级文件 `&lcdif` 下再写一整棵 `display0: display { ... }` | 时序生效，但写法不干净；易与基线子节点纠缠 |
| D. 板上验证 | TFTP 定制 dtb done；`virtual_size=1024,600`；`mxsfb initialized` | 软件分辨率 OK |
| E. 背光命令 | `echo 7 > .../*/brightness` 失败；`echo 8/10` → Invalid argument | ash 不展开 `*`；亮度下标仅 **0~7** |
| F. 日志干扰项 | `Duplicate name ... display#1`；`failed to find mxc display driver` | 见下文「可忽略项」；不阻显示 |
| G. 收尾写法 | 改为 `&display0` / `&timing0` 属性覆盖 | 与基线合并更干净；屏显确认打通 ✅ |

## 三、根因与修复

### 问题 1：定制 dtb 名是 1024-600，内容仍是 480×272

**根因**

```text
imx6ull-14x14-evk-emmc-gengtao0901-1024-600.dts
  └── #include imx6ull-14x14-evk-gengtao0901.dts   ← 内含 &lcdif 默认 480×272
板级定制区最初未覆盖 timing → 编出的 dtb 分辨率错误
```

**修复**：基线 `&lcdif` 只保留 pinctrl；板级 `*-1024-600.dts` 内用**一个** `&lcdif` 块写齐 display + timings：

```dts
&lcdif {
	display = <&display0>;

	display0: display {
		bits-per-pixel = <16>;
		bus-width = <24>;

		display-timings {
			native-mode = <&timing0>;
			timing0: timing0 {
				clock-frequency = <51200000>;
				hactive = <1024>;
				vactive = <600>;
				hfront-porch = <160>;
				hback-porch = <140>;
				hsync-len = <20>;
				vfront-porch = <12>;
				vback-porch = <20>;
				vsync-len = <3>;
				hsync-active = <0>;
				vsync-active = <0>;
				de-active = <1>;
				pixelclk-active = <0>;
			};
		};
	};
};
```

**自检**

```bash
dtc -I dtb -O dts tftpboot/imx6ull-14x14-evk-emmc-gengtao0901-1024-600.dtb \
  | grep -E 'hactive|vactive|clock-frequency'
# hactive=<0x400>  vactive=<0x258>  clock-frequency=<0x30d4000>
```

### 问题 2：时序配置曾拆成 `&display0` / `&timing0` 两处

**原因**：想用 label 增量覆盖，避免在基线已有 `display` 子节点时再嵌一套。  
**调整**：基线去掉默认小屏 display；板级把该屏的 display+timings **集中写在同一个 `&lcdif` 块**，可读性更好。

### 问题 3：背光 sysfs 用法

| 错误写法 | 原因 |
|----------|------|
| `echo 7 > /sys/class/backlight/*/brightness` | busybox ash 重定向路径里的 `*` **不展开** |
| `echo 8` / `echo 10` | `brightness-levels` 只有 8 档，合法下标 **0~7**，超出 → `Invalid argument` |

**正确写法**

```bash
cat /sys/class/backlight/backlight/max_brightness   # 7
echo 7 > /sys/class/backlight/backlight/brightness
```

对应 dts：

```dts
brightness-levels = <0 4 8 16 32 64 128 255>;
default-brightness-level = <6>;
```

## 四、可忽略的日志（避免误判）

| 日志 | 含义 |
|------|------|
| `device-tree: Duplicate name in lcdif@..., renamed to "display#1"` | `lcdif` 下既有属性 `display = <&display0>`，又有子节点名 `display`，OF 命名空间冲突；NXP EVK 常见，子节点被改名，**不挡显示** |
| `mxsfb ... failed to find mxc display driver` | 未走独立 mxc display 设备；有 `display-timings` 时 mxsfb 仍会 `initialized` |
| `21c8000.lcdif supply lcd not found` / `backlight supply power not found` | 无独立 regulator，用 dummy，可忽略 |

有效成功信号：

```text
Console: switching to colour frame buffer device 128x37
mxsfb 21c8000.lcdif: initialized
```

`128x37` ≈ 1024/8 × 600/16，与 1024×600、16bpp 一致。

## 五、最终验收（板上）

```bash
# 分辨率
cat /sys/class/graphics/fb0/virtual_size    # 1024,600
cat /sys/class/graphics/fb0/bits_per_pixel # 16

# 背光
echo 7 > /sys/class/backlight/backlight/brightness

# 刷屏（应看到噪点/雪花）
dd if=/dev/urandom of=/dev/fb0 bs=1024 count=1200
```

| 项 | 结果 |
|----|------|
| TFTP `...gengtao0901-1024-600.dtb` Loading done | ✅ |
| `/dev/fb0` 存在 | ✅ |
| `virtual_size=1024,600`，bpp=16 | ✅ |
| 背光 0~7 可写 | ✅ |
| 屏上可见刷屏内容 | ✅ 已打通 |

U-Boot 加载（写死文件名，见 03/06）：

## 七、经验沉淀

1. **文件名不等于设备树内容**：`1024-600` 只是命名；必须用 `dtc` 反编译或板上 `virtual_size` 验证。  
2. **屏参集中、引脚在基线**：分辨率/时序放在板级变体同一个 `&lcdif` 块；pinctrl/背光留在共用基线。  
3. **先软件分辨率，再眼睛确认**：`fb0` 对了再调背光/排线；全黑时先查 `max_brightness` 与亮度下标。  
4. **分清噪音日志**：`display#1` / `failed to find mxc display driver` 不等于没驱动起来。  
5. **与网卡复盘同一纪律**：只改 overlay；bootcmd 写死 dtb；TFTP 必须 `Loading done`。
